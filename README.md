# Slay English Bot — новая сборка

## Установка
1. Распакуй архив.
2. Создай копию `.env.example` с именем `.env`.
3. В `.env` вставь новый токен BotFather. Не публикуй `.env` в GitHub.
4. Проверь ADMIN_IDS: `1105059220,5688806795` — сестра и ты.
5. Установи Python 3.11 и зависимости: `py -m pip install -r requirements.txt`
6. Запуск: `py bot.py`

## Админка
`/admin`
- Материалы и курсы: добавить название, описание, файл или ссылку. Нажатие по существующей записи переключает активность.
- Рассылка: текст/фото/видео/документ, кнопки ссылок в формате `Название | https://...`, интервал 1/6/12/24 ч, срок 1/6/12/24 ч или навсегда.
- Реклама: то же самое, интервал 1/3/6/12 ч.
- Вставочная реклама: после выдачи бесплатного материала отправляется активная кампания «Реклама».

## Важно
- Бот должен быть администратором канала `@english_slay` для проверки подписки.
- Бот пишет только пользователям, которые запускали его сами.
- Предыдущая копия кампании удаляется при следующей отправке. По окончании срока кампания останавливается; последнее сообщение останется в чате.
- Telegram не предоставляет боту отметку о прочтении сообщения.
- Не загружай `.env`, `bot.db`, `.venv` и `__pycache__` в GitHub.
