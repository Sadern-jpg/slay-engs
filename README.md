# Slay English

Python 3.11, aiogram 3.22.0, aiosqlite, SQLite. Один процесс long-polling.

## Railway
1. Загрузить содержимое архива в GitHub-репозиторий.
2. В Railway создать сервис из GitHub-репозитория. Сборка определяется Dockerfile.
3. Добавить Railway Volume и смонтировать его в `/data`.
4. Добавить Variables:
   - `BOT_TOKEN` — токен от BotFather
   - `ADMIN_IDS` — `1105059220,5688806795`
   - `CHANNEL_ID` — `@english_slay`
   - `CHANNEL_URL` — `https://t.me/english_slay`
   - `DB_PATH` — `/data/bot.db`
5. Запустить один экземпляр сервиса. Не включать несколько реплик.

## Важно
- Не добавлять токен в GitHub.
- Бот должен быть администратором канала или иметь доступ, позволяющий проверять участников.
- Удаление ранее отправленных сообщений Telegram может запрещать в отдельных случаях (например, возраст сообщения/права); бот продолжит кампанию.
- FSM админ-панели хранится в памяти: незавершённый сценарий сбросится после перезапуска.
- Для первой проверки отправить `/start` боту, затем администратору открыть панель и добавить материалы.
