# Slay English Bot — исправленная сборка

## Настройка
1. Используй Python 3.11.
2. Создай `.env` на основе `.env.example` (локально) или добавь переменные в настройках хостинга.
3. Укажи BOT_TOKEN, ADMIN_IDS, CHANNEL_ID, CHANNEL_URL, DB_PATH.
4. Установи зависимости: `python -m pip install -r requirements.txt`
5. Запусти: `python bot.py`

## Админ-панель
Команда `/admin`.
- Материалы: название, описание, файл или ссылка. Нажатие на существующий пункт включает/выключает его.
- Курсы: аналогичное управление.
- Рассылка: текст/фото/видео/документ, ссылки-кнопки, интервал 1/6/12/24 ч, срок 1/6/12/24 ч или навсегда.
- Реклама: текст/фото/видео/документ, ссылки-кнопки, интервал 1/3/6/12 ч.
- Рекламная вставка: отдельное сообщение, которое отправляется после выдачи бесплатного материала.

## Важно
- Бот должен быть администратором канала для проверки подписки.
- Пользователь должен хотя бы раз нажать `/start`, чтобы попасть в список рассылки.
- Telegram не сообщает боту, прочитал ли пользователь сообщение.
- При повторной отправке регулярной рекламы/рассылки бот пытается удалить предыдущее сообщение этой же кампании у пользователя.
- По окончании срока рассылка останавливается; последнее отправленное сообщение не удаляется автоматически.
- В этой сборке кнопки управления материалами переключают активность; физическое удаление записей через интерфейс пока не предусмотрено.
- Не публикуй `.env`, токен или `bot.db` в GitHub.
