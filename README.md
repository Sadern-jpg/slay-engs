# Slay English Bot

## Установка (Windows / PowerShell)

1. Установи Python 3.11 или 3.12.
2. Открой папку проекта в VS Code.
3. В терминале выполни:

```powershell
py -m venv .venv
.venv\Scripts\Activate.ps1
py -m pip install -r requirements.txt
```

4. Скопируй `.env.example` в файл `.env` (именно `.env`, без `.txt`).
5. Вставь новый токен BotFather в `BOT_TOKEN`.
6. В `ADMIN_IDS` укажи ID администраторов через запятую.
7. Запусти `py bot.py`.

## Функции
- Меню: «Забрать бесплатные материалы» и «Буст твоего английского».
- Подписка проверяется непосредственно перед каждой выдачей материала.
- Админка: добавление PDF/ссылок и курсов, включение/выключение/удаление, статистика.
- Рассылка текста, фото, видео и документов всем пользователям, запускавшим бота.
- Напоминание через 24 часа после первого получения материала.

## Важно о напоминании
Telegram не сообщает ботам, прочитал ли пользователь сообщение. Поэтому повторяем напоминание каждые 24 часа до нажатия «Понятно, спасибо 🩷». Кнопка «Записаться» ведёт на https://t.me/kot_begemot3, отзывы — https://t.me/slaytalks.

## Важно
Добавь бота администратором канала @english_slay, чтобы Telegram позволил проверять подписку. Не удаляй `bot.db`: там база пользователей, материалов и курсов. Делай резервные копии.


## Периодическая рассылка на запись на занятия

В админ-панели есть кнопка «⏰ Рассылка на занятия». Администратор может:
1. Задать или заменить одно сообщение (текст, фото с подписью, видео или документ). Ссылки можно вставить прямо в текст/подпись.
2. Выбрать интервал: 2, 4, 6 или 12 часов.
3. Включить или остановить автоматическую рассылку.

После включения первое сообщение отправится через выбранный интервал. Далее рассылка повторяется с тем же интервалом, пока администратор её не остановит. Настройки сохраняются в SQLite и переживают перезапуск бота. Сообщения отправляются пользователям, которые ранее запускали бота; заблокировавшим бота Telegram доставку не гарантирует.

Если нужно изменить текст, фото или ссылки, откройте «Рассылка на занятия» → «Изменить текст / фото / ссылки» и сохраните новое сообщение. Для текста со ссылками можно использовать обычные URL или HTML-ссылки вида `<a href="https://example.com">Записаться</a>`.
