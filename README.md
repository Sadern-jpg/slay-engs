# Slay English Telegram Bot

Python 3.11 · aiogram 3 · aiosqlite · SQLite.

## Что умеет бот

- Приветствие и меню Slay English.
- Бесплатные материалы с обязательной проверкой подписки на `CHANNEL_ID`.
- Если пользователь сначала выбрал материал, а затем подписался, бот выдаёт именно выбранный материал после нажатия «Проверить подписку».
- Курсы без проверки подписки.
- Админ-панель `/admin`: добавление материалов/курсов, включение и выключение, удаление, постраничный список.
- Рассылка с интервалами 1/6/12/24 часа и сроком 1/6/12/24 часа или «навсегда».
- Реклама с интервалами 1/3/6/12 часов.
- Рекламная вставка после выдачи бесплатного материала.
- Контент кампаний: текст, фото, видео, документ, аудио, GIF; ссылки-кнопки.
- Повторные попытки при Telegram flood control и временных сетевых ошибках.
- Исключение пользователей, заблокировавших бота, из последующих рассылок.
- Аддитивная миграция базы: новые столбцы добавляются без удаления существующих таблиц и записей.

## Запуск локально

```bash
python -m pip install -r requirements.txt
python bot.py
```

## Переменные окружения

Скопируйте `.env.example` в `.env` локально или задайте переменные в настройках хостинга:

- `BOT_TOKEN` — токен от BotFather.
- `ADMIN_IDS` — Telegram ID администраторов через запятую.
- `CHANNEL_ID` — username канала, например `@english_slay`.
- `CHANNEL_URL` — ссылка на канал.
- `DB_PATH` — путь к SQLite базе. Для BotHost с постоянным хранилищем используйте `/app/data/bot.db`, если платформа монтирует `/app/data`.

**Важно для существующего бота:** сначала выясните, где лежит действующая база, и укажите тот же `DB_PATH`. Не переключайте путь на новую пустую базу, если хотите сохранить пользователей и материалы. Сделайте резервную копию `bot.db` перед обновлением. Код не удаляет старые таблицы.

Не загружайте `.env`, токен и `bot.db` в GitHub. Если токен когда-либо попадал в скриншоты или переписку, отзовите его через BotFather `/revoke` и задайте новый в переменных окружения.

## Docker

Dockerfile проекта устанавливает только зависимости из `requirements.txt` и запускает `python bot.py`. Используется aiogram 3; `aiogram.utils.executor` не нужен и не должен вызываться. Если панель хостинга запускает дополнительную собственную команду сборки с импортом `executor`, её нужно удалить в настройках хостинга или переключить сборку на Dockerfile репозитория. Изменение Python-кода не может отменить команду, выполняемую хостингом до сборки контейнера.

## Ограничения Telegram

- Бот должен быть администратором канала или иметь доступ, достаточный для `getChatMember`, иначе проверка подписки может не работать.
- Пользователь попадает в аудиторию рассылки после `/start`.
- Удаление старого сообщения может быть запрещено Telegram; в таком случае новое сообщение всё равно отправляется.
- Telegram не предоставляет боту достоверную информацию о прочтении сообщения.
- Если срок рассылки закончился, кампания прекращается; уже доставленное последнее сообщение автоматически не удаляется.
- FSM-диалог админки хранится в памяти и сбрасывается при перезапуске процесса.

## Установка на хостинг

1. Загрузите содержимое архива в корень репозитория, чтобы `bot.py`, `Dockerfile` и `requirements.txt` лежали рядом.
2. Настройте переменные окружения на хостинге. Не загружайте `.env` в GitHub.
3. Убедитесь, что используется Dockerfile из репозитория, а не старая пользовательская команда сборки с `executor`.
4. Убедитесь, что запущен только один экземпляр бота с этим токеном (одновременный polling в двух местах вызывает конфликт).
5. После старта проверьте `/start`, затем `/admin` с аккаунта администратора.
