# Slay English — обновление на основе исходной версии

Проект сохранён на исходной структуре aiogram 3.22.0. Добавлены/исправлены: админ-управление материалами и курсами (вкл/выкл/удаление), сохранение выбранного материала до проверки подписки, рекламная вставка после бесплатного материала, отдельные настройки рассылки и рекламы, поддержка дополнительных типов Telegram-файлов.

## Переменные окружения
- `BOT_TOKEN` — токен из BotFather (только в настройках хостинга)
- `ADMIN_IDS=1105059220,5688806795`
- `CHANNEL_ID=@english_slay`
- `CHANNEL_URL=https://t.me/english_slay`
- `DB_PATH=bot.db`

## Запуск
`pip install -r requirements.txt`
`python bot.py`

Бот должен быть администратором канала @english_slay, чтобы проверять подписку.
