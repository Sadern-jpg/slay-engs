# Slay English Bot

## Установка (Windows / PowerShell)

1. Установи Python 3.11 или 3.12.
2. Открой папку проекта в VS Code.
3. В терминале выполни:

```powershell
py -m venv .venv
.venv\Scripts\Activate.ps1
py -m pip install -r requirements.txt
```

4. Скопируй `.env.example` в файл `.env` (именно `.env`, без `.txt`).
5. Вставь новый токен BotFather в `BOT_TOKEN`.
6. В `ADMIN_IDS` укажи ID администраторов через запятую.
7. Запусти `py bot.py`.

## Функции
- Меню: «Забрать бесплатные материалы» и «Буст твоего английского».
- Подписка проверяется непосредственно перед каждой выдачей материала.
- Админка: добавление PDF/ссылок и курсов, включение/выключение/удаление, статистика.
- Рассылка текста, фото, видео и документов всем пользователям, запускавшим бота.
- Напоминание через 24 часа после первого получения материала.

Telegram не сообщает ботам, прочитал ли пользователь сообщение. Поэтому повторяем напоминание каждые 24 часа до нажатия «Понятно, спасибо 🩷». Кнопка «Записаться» ведёт на https://t.me/kot_begemot3, отзывы — https://t.me/slaytalks.
